# 🏫 Agenda de Eventos Escolares - Escola Futuro do Saber

Projeto de uma aplicação web responsiva para gerenciamento e consulta de eventos da escola.

## 🚀 Tecnologias Utilizadas
- HTML5 (Semântico)
- CSS3 (Flexbox, CSS Grid e Responsividade)
- JavaScript (Manipulação de DOM, Filtros, Array e Contador Regressivo)

## 📌 Funcionalidades
- **Filtro por Categoria:** Filtre eventos por Esportes, Educação, Cultura ou Tecnologia.
- **Pesquisa em Tempo Real:** Pesquise por nome do evento ou local.
- **Modal de Detalhes:** Clique em "Ver Detalhes" para visualizar a descrição completa.
- **Contador Regressivo:** Acompanhe a contagem regressiva para o próximo grande evento.
- **Formulário de Inscrição:** Registre interesse em qualquer evento listado.

## 🔗 Publicação no GitHub Pages
1. Crie um repositório no GitHub chamado `agenda-eventos`.
2. Faça o commit e push de todos os arquivos.
3. Vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e salve.
